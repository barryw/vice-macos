The VICE pieces a Mac app actually needs.

Engine control

Start, pause, reset, type text, send keys, and coordinate emulator lifetime from Swift.

Metal display

Media helpers

Input routing

Callbacks

Observe video frames, audio samples, drive status, cartridge status, VSID data, and SID voices.

Debugger APIs

Peek, poke, disassemble, step, manage breakpoints, and inspect registers from native tools.

Quick start

A C64 display in a SwiftUI view.

This starts x64sc, renders it with Metal, and feeds a tiny BASIC program through VICE's keyboard buffer. 

import SwiftUI
import MacVICEKit

struct EmulatorView: View {
    @State private var session = MacVICEEngineSession(
        configuration: MacVICEMachineConfiguration(
            machine: .c64sc,
            runtimeLocation: .automatic
        )
    )
    @State private var didStart = false

    var body: some View {
        MacVICEDisplayView(session: session)
            .frame(minWidth: 768, minHeight: 544)
            .task {
                guard !didStart else {
                    return
                }
                didStart = true

                do {
                    try session.start()
                } catch {
                    assertionFailure(error.localizedDescription)
                    return
                }

                session.typeText("10 PRINT \"HELLO FROM MACVICEKIT\"\n20 GOTO 10\nRUN\n")
            }
    }
}

Runtime included

No Homebrew, shell scripts, or local VICE build required.

The release SDK includes Runtime/MacVICERuntime.xcframework. Xcode embeds the runtime binary target when your app depends on the MacVICEKit product.

Supported machines

x64sc, x128, xvic, xpet, xplus4, xc16, xc232, xv364, and vsid.

Runtime lookup

.automatic checks an explicit runtime directory, embedded framework layouts, app bundle Frameworks, and local development builds.
